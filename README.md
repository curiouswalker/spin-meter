# スピンメーター

リストボールの回転音をマイクで拾い、回転数・強度ゾーン・左右バランスを記録するWebアプリ。

- 公開URL: Netlify（このリポジトリの `main` を自動デプロイ）
- 使い方: 「計測スタート」でマイク計測、または録音ファイル（m4a / mp3 / wav）を解析
- 記録は各ブラウザの中（localStorage）にだけ保存されます

## しくみ
- 回転音は回転数に比例した高さの倍音列（櫛形のスペクトル）になる。倍音の間隔 = 基音 (Hz)、`Hz × 60 = RPM`（「校正と感度」で換算を変更可）
- 持ち替え = 回転音が短く途切れ、そこに「カチッ」という音があるとき（前回の持ち替えから8秒以上回転し、その後3秒以上回転が続く場合のみ）
- 持ち替え時の雑音や一瞬の跳ね上がり（周囲より25%以上高い値、3秒未満の回転）は集計から除外

## ファイル

- `index.html` — 公開用。`scripts/build.sh` で `src/app.html` から生成
